# CSD 310 - Database Development and Use

Wade Eckert's Repository for CSD 310: Database Development and Use. 

This repository contains my coursework and programming assignments completed for **CSD 310 - Database Development and Use** at Bellevue University. Throughout this course, I learned the principles of relational database design, SQL programming, database normalization, and how software applications interact with databases using Python.

Assignments progressed from learning fundamental SQL statements and database concepts to designing and implementing complete relational database solutions based on real-world business requirements.
